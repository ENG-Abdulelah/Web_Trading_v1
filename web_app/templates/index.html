دليل الاستخدام والتوثيق

بدء التشغيل

ثبّت المتطلبات عبر pip install -r requirements.txt ثم شغّل التطبيق بـ python app.py. سيكون متاحاً على http://localhost:5000.

قراءة الصفقات الحية

تبويب "الصفقات الحية" يعرض كل صفقة نشطة مع رمز الأداة، الاتجاه، سعر الدخول، الهدف، ووقف الخسارة. الشارات الملوّنة تُظهر الإطار الزمني (1W/1D/4H/1H/5M) ونمط التداول (Swing / Scalping).

متابعة الأوامر المعلقة

تبويب "الأوامر المعلقة" يعرض الأوامر (Limit/Stop) التي لم تُفعَّل بعد. راقب الفرق بين السعر الحالي وسعر الدخول لتقدير قرب التنفيذ.

تحليل الصفقات المنتهية

تبويب "الصفقات المنتهية" يُتيح مراجعة الأداء التاريخي، النتائج بالربح/الخسارة، ونسبة النجاح الكلية المعروضة في شريط الإحصائيات العلوي.

مراقبة الأخبار الاقتصادية

قسم الأخبار يعرض 6 مصادر منفصلة: ForexFactory، Investing.com، FXDaily، CPI، COT، CFTC. النقاط الملوّنة تُشير لمستوى التأثير (أحمر = عالي، أصفر = متوسط، أخضر = منخفض).

متابعة استراتيجيات ICT

جدول الترتيب يعرض الـ 20 استراتيجية مرتّبة حسب نسبة النجاح، مع عدد مرات الاستخدام وشريط تقدّم بصري لكل استراتيجية لمساعدتك في تفضيل الأنسب.

ضبط الاستراتيجيات

يمكنك تعديل قائمة الاستراتيجيات من خلال الدالة get_strategy_rankings() في app.py — أضف/احذف/عدّل الأسماء والنِسب لتعكس أداء البوت الفعلي.

تنبيهات الإشارات

عند ظهور إشارة جديدة، تُضاف تلقائياً إلى تبويب "الصفقات الحية" أو "الأوامر المعلقة" حسب نوع الإشارة (Market / Pending). تحقّق دورياً من تحديث الصفحة.
